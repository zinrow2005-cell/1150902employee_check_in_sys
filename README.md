- 定位自拍上下班打卡與 LINE 分享

- 請假、預排休假、休假日期調整、補卡、加班
- 請假編輯／撤回／取消申請
- 本人出勤與正式薪資單

## W444 操作防呆

- 已用完且可明確計算剩餘額度的假別會顯示「剩餘 0 日｜不可申請」，不能建立新申請。
- 請假開始日期變更時，結束日期會先跟到同一天；若為連續請假，再自行把結束日期往後選。
- 工作月曆中的休假日期調整送出後，結果會直接顯示在按鈕下方。

## 工作資料來源

### 工作項目表
主系統「生產批次事件月曆」→「重新產生月曆」→「同步工作到員工端」，或到「出勤管理中心」按「同步打卡＋員工自助中心」。

### 我的工作任務
