# 王泰山畜牧場｜GitHub 員工自助端 W432 FIX368R5

這是目前正式的 **CLEAN R1 乾淨封裝**。功能版本仍是 W432 FIX368R5，CLEAN R1 只代表重新整理檔案，不改 API 或打卡邏輯。

## 正式功能
- 員工編號＋6 位 PIN，登入後同裝置維持 15 天 Session。
- iPhone／iPad 使用 iOS 系統相機，避免 WebRTC 黑屏。
- Android／其他支援裝置保留即時相機，並驗證真實非黑影像。
- 上班／下班、多段打卡、GPS／地名、LINE 分享及主系統回傳。
- 我的出勤、我的班表、工作項目表、工作任務、請假／調休／補卡／加班、薪資單。
- R5 打卡照片浮水印：牧場書法圖示、大字台灣時間、員工／部門／定位資訊；上班綠色、下班金色。

## 部署
把本資料夾內容直接覆蓋 GitHub Pages repository 根目錄即可。

Apps Script 在 R5 沒有功能修改；如果你目前已是 W432 FIX368 的 Code.gs，不需要重新部署。
