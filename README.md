# 王泰山畜牧場｜GitHub 員工自助端 W435 FIX371

本版新增員工請假申請的完整後續處理：

- 待同步／待審中的請假可 **編輯**。
- 待審中的請假可 **撤回**，主系統同步後保留稽核紀錄。
- 已駁回／同步失敗的請假可 **修改後重新送出**。
- 已核准／已成立／已排定的請假不可直接刪除，改為 **申請取消請假**，由主管審核。
- 取消請假核准後，主系統會移除原請假的工作月曆／假別台帳影響並保留歷史紀錄。
- 延續 W434 FIX370 的台灣日期可讀化與日期正規化。
