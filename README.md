## 工作資料來源

### 工作項目表
主系統「全場工作與人力排程」中的現場／手動工作會優先同步，並合併「生產批次事件月曆」的重大工作。空場或尚未設定第一批開始日時，也可以先建立清洗、消毒、修繕、盤點等手動工作，再到「生產批次事件月曆」按「同步工作到員工端」。

### 我的工作任務
主系統「全場工作與人力排程」→「人力配置與排班橋接」指定主責／支援員工 → 排班審核核准後，員工端立即顯示「已指派・待薪資同步」的唯讀任務。薪資排班審核核准同步後，會自動轉成正式可回報任務，不會重複顯示。
